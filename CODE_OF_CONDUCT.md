# Code of conduct

Be straightforward and be kind. Disagree with the claim rather than the person
making it, and assume the person you are disagreeing with has a reason you have
not heard yet.

This repository is about hiring, which is a subject people have been hurt by.
Accounts of a bad process are welcome; naming the company or the individual is
not, and `check_generic.py` refuses it in the book for the same reason it is
refused in an issue.

Unacceptable: harassment, personal attacks, and publishing anybody's private
information.

Report anything that needs reporting through a private security advisory on the
repository, which is the only private channel this project has.
