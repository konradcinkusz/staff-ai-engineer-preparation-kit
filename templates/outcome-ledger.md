# Outcome ledger

Chapter 18. One row per process, kept forever. The only document in this kit
that is worth more the longer you keep it.

One process tells you almost nothing — outcomes at this level are noisy and a
single rejection is weak evidence about anything. Four rows with a pattern in
the last column tell you where your actual constraint is, and nothing else
will.

| | | | | / | | above / below | |

## Reading it

Count the rows by class.

- **Mostly above the line** — preparation is the lever. Keep going, and use the
  retrospectives to find which class above the line.
- **Mostly below the line** — preparation is not the lever, and more of it will
  not help. The options are in Chapter 13: prepare the answer, change the
  target, or fix it on a different timescale.
- **Mixed** — look at the stage column. If the below-the-line endings all come
  late, the early stages are working and something specific is being weighed at
  the end.
