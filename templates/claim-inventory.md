# Claim inventory

Chapter 10. Every sentence in an application that could be checked. About an
hour the first time, and it reliably finds three things: a number at two
precisions in two documents, a claim whose backing turns out to be a memory,
and a capability described more strongly in the letter than in the repository.

## The table

| Claim, as written | Where it appears | Backed by | Strength | Last checked |
|---|---|---|---|---|
| | CV / letter / form / README | file, commit, measurement, person | measured / observed / reported / judgement | |

Strength decides the wording:

- **measured** — state it flatly
- **observed** — put the occasion in the sentence
- **reported** — say where it came from
- **judgement** — mark it as judgement, or cut it

## Blank backings

A claim with nothing in the *Backed by* column is not a claim, it is a hope.

Remove it. Do not soften it — a softened unbacked claim is still unbacked and
now reads as evasive.
