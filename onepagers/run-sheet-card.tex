\section{The first slice}
The one path that must work \dash\ through every layer \dash\ containing
the \warn{hardest thing} \dash\ demonstrable. May skip auth, validation,
styling, config, every other entity. \warn{May not skip its assertion.}

\section{Compress the procedure, never the criterion}
Fewer questions, less drawing, less narration. But if the slice was going to
prove the conflict case, it still has to prove it. Cutting it silently is
worse than saying you cut it.

\section{The closing block is not spare}
\begin{enumerate}[nosep]
  \item Show it working \dash\ \textbf{in the product}, not the API explorer.
  \item What I cut, against the agreed out-of-scope line.
  \item What I would do next, and what worries me.
\end{enumerate}

\section{Prepared / not prepared}
\textbf{May:} method, questions, vocabulary, tooling, skeleton, this card.\\
\textbf{May not:} entities, relationships, endpoints, acceptance criteria.
\warn{A prepared data model destroys the first scored criterion.}
