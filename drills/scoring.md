## Row 3 is the one

If you track one thing across several rehearsals, track when discovery closed.
Everything downstream inherits its slippage, and unlike the other rows it is a
single number you can read off the recording without judgement.

## What to do next

Take the **three worst rows**. Drill those, twenty minutes each, in isolation —
not by running the whole thing again. A second full run mostly re-measures;
twenty minutes on the weakest row changes it.

| Weak row | The isolated drill |
|---|---|
| 1, 2 | ten minutes of discovery only, new brief, no building |
| 3 | the same, with a hard stop at the checkpoint |
| 7 | narrate a build you already know how to do, alone, watching for silences |
| 8 | thirty minutes of assisted building, counting rejections |
| 9 | build one hard case end to end with its check, nothing else |
| 10, 11 | the closing five minutes only, repeatedly |
